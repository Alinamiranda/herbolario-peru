
# Herbolario Perú 🌿

Plataforma web que conecta compradores con herbolarios y tiendas naturistas del Perú.

## Objetivo
Facilitar la búsqueda de establecimientos, consulta de productos naturales e información sobre plantas medicinales.

## Tecnologías
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Git y GitHub
- Vercel

## Desarrollo
Proyecto académico desarrollado aplicando metodologías ágiles Scrum y prácticas DevSecOps.

## Ramas
- main: versión estable.
- test: desarrollo y pruebas.
