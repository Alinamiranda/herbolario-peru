# Despliegue y autenticación

Next.js 16 usa identificadores de Server Actions asociados al build. Una página abierta de un despliegue anterior puede enviar una acción que el servidor más reciente ya no reconoce. En Vercel, comprueba en Settings → Advanced que Skew Protection esté disponible y habilitada para el proyecto, que se expongan las variables de sistema y que el framework detectado sea Next.js. Consulta la disponibilidad y configuración del plan en la [documentación de Vercel](https://vercel.com/docs/skew-protection). La protección del proveedor enruta las solicitudes de framework al despliegue compatible mientras este siga disponible; `deploymentId` por sí solo no proporciona ese enrutamiento. Una pestaña anterior a la habilitación o un despliegue ya retirado puede requerir recargar la página y volver a enviar el formulario manualmente. No se debe reenviar automáticamente una operación que pudo haberse completado.

En Vercel configura `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` y `NEXT_PUBLIC_SITE_URL` en los entornos correspondientes. La URL de sitio debe ser el origen real de la aplicación, sin barra final, y debe estar permitida junto con `/auth/callback` en Supabase Auth. Utiliza solamente la clave publicable o anon en las variables `NEXT_PUBLIC_`; nunca una clave secreta o service role. Revisa que el despliegue de producción use la rama prevista y reconstruye después de cambiar variables. No es necesario fijar `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` para resolver un identificador de acción inexistente: esa clave tiene otro propósito y no mantiene IDs entre builds.

El cliente de Supabase en servidor espera una conexión de usuario antes de inicializar Auth. Esto evita ejecutar las comprobaciones de expiración de sesión durante el prerenderizado con Cache Components. Verifica en un despliegue de prueba las páginas `/`, `/cuenta`, `/directorio` y `/cuenta/perfil`, tanto sin sesión como con una sesión real. Comprueba también el registro de compradores y vendedores y la confirmación por correo en el proyecto Supabase configurado.
